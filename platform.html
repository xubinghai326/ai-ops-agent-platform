Platform Scope

先证明“能跑通”，再接入真实业务

当前 Demo 不追求复杂能力，而是优先验证一个真实闭环：输入文本 -> Manager 路由 -> Worker 执行 -> 统一结果输出 -> 人工确认建议。

01. 输入层 录入玩家反馈 / 客服工单 / 社区文本。 02. Manager 节点 识别意图、判断优先级并决定调用哪些 Worker。 03. Worker 层 执行分类、摘要、相似案例检索和公告草稿生成。 04. 输出层 返回内部处理建议和结构化任务单。
