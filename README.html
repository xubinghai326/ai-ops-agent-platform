这个项目是做什么的

这是一个在短时间内构建的 AI 运营 Agent 平台 MVP，用于证明通用输入场景下，Manager + Worker 架构能够完成运营问题理解、路由、处理与结果输出闭环。

Project Scope

先验证架构方向，
再逐步接入真实业务工具

当前阶段并不追求“大而全”，而是先搭出一个真正能演示的底座：输入一段玩家反馈、客服工单或社区文本，平台完成分类、路由、Worker 执行和结构化结果输出。

当前阶段 MVP

短期内交付，优先证明平台闭环成立。

当前能力 通用问题处理

支持网络异常、数值问题、剧情吐槽等典型输入。

后续扩展 可接真实 Worker

后续可逐步接入日志分析、分群统计、FAQ 检索等真实业务能力。

当前 MVP 目标

先把平台的基本协作机制做通。

Goal
输入事件标准化

把玩家反馈、工单和社区文本统一成可处理的输入对象。

Manager 路由成立

能识别问题类型、判断优先级，并选择对应 Worker。

Worker 闭环可跑

至少能完成分类、相似案例检索、摘要和公告草稿生成。

结构化输出

输出内部处理建议、公告草稿和结构化任务单，供人工确认。

当前不做什么

避免两天内把项目做成大而空。

Not in Scope
不直接接真实生产数据库

先验证平台交互与路由逻辑，不在本阶段承担数据安全和权限复杂度。

不自动执行高风险动作

当前只生成建议、摘要和草稿，不直接发奖、不改配置、不对外发布。

不在第一阶段做复杂多 Agent 记忆系统

先把 Manager + Worker 最小闭环证明成立，再考虑长期记忆和复杂编排。
